\# Advertising Sales Prediction



\## Project Overview



This project predicts product sales based on advertising expenditure on TV, Radio, and Newspaper.



The project uses Machine Learning with Linear Regression and provides a Streamlit web application for making predictions.



\## Dataset



The dataset contains the following columns:



\- TV

\- Radio

\- Newspaper

\- Sales



The dataset contains 10,273 rows and 4 columns.



During preprocessing, one row containing missing values was removed. The remaining 10,272 rows were used for the project.



Duplicate rows were retained so that the complete usable dataset could be used.
